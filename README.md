Deskripsi Proyek

Latihan ini difokuskan pada pemahaman cara Flutter menyusun UI, penerapan 3 aturan mutlak layout (Constraints go down, Sizes go up, Parent sets position), serta praktik memecah komponen UI menjadi Custom Widget (Refactoring/Extract Widget). Proyek ini dikerjakan dengan menerapkan kedisiplinan version control menggunakan Conventional Commits.

Jurnal Progres (Commit Management)

Hari 1: Pemahaman Dasar Layout (✅ Selesai)

Menguji coba 3 Aturan Dasar Layout menggunakan ConstrainedBox, Center, dan Align.

Menyelesaikan masalah layouting posisi widget.

Menerapkan commit feat, fix, dan refactor untuk merapikan kodingan yang tidak terpakai.

Hari 2: Kerangka Profil & Refactoring Awal (✅ Selesai)

Membangun kerangka utama halaman profil menggunakan Scaffold, AppBar, CircleAvatar, dan Text.

Melakukan refactor (Extract Widget) dengan memecah antarmuka menjadi komponen mandiri (ProfileAvatar dan ProfileInfo).

Menerapkan 2 kali push harian (feat dan refactor).
